# 🌘 Eclipse Guide UK 2026

A space-themed Progressive Web App designed to help people safely experience the **12 August 2026 solar eclipse** in the UK.

---

## 🚀 Features

🌘 **Eclipse Countdown**
- Live countdown to the eclipse
- Shows days, hours, minutes and seconds

📖 **Eclipse Guide**
- Eclipse information
- UK visibility details
- Safety information
- Eclipse timeline simulator

🧭 **Find The Eclipse**
- Direction finder
- Location support
- Manual viewing guide

📺 **Watch Live**
- Space agency and observatory streams
- Live eclipse coverage

🛒 **Eclipse Viewing Kit Shop**
- Eclipse glasses kit
- Phone solar filter
- Mini guide book
- Payment link integration

⚙️ **Settings**
- Dark mode
- Animation controls
- App information
